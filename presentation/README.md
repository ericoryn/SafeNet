# Питч SafeNet KZ

Обновлено 25.10.2026. 10 основных слайдов на пять минут и 2 приложения.

- [PDF для показа](SafeNet_KZ_Защита.pdf)
- [Редактируемый PowerPoint](SafeNet_KZ_Защита.pptx), текст и фигуры редактируются, снимки интерфейса встроены как изображения.
- [Текст выступления](Текст_выступления.md), также в заметках слайдов.
- [Обзор](Обзор_слайдов.png) и [источники утверждений](Слайды_и_источники.json).

Числа извлекаются сборщиком из машинных отчётов, первый test сохранён отдельно. Снимки показывают текущий локальный сайт на синтетических данных. Повторная оценка test не независима и не доказывает реальную точность.

Сборка: Node.js с установленным pptxgenjs → `node presentation/build.cjs`; Playwright и Sharp → `node presentation/render.cjs`. PDF и PNG рендерятся из синхронной HTML-версии. Нативный рендеринг PowerPoint и живая репетиция не выполнены.
