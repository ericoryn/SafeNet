# Доработка UX/UI — 25 октября 2026

## Что изменено

- Фильтры применяются при выборе значения. Для дат проверяется порядок; исправление ошибочного диапазона сразу возобновляет фильтрацию.
- Очередь получила более читаемые превью, подписи полей и отдельные карточки на телефоне. Сохранены текущая палитра и удаление ранее отмеченных пользователем надписей.
- Карточка и граф показывают загрузку. Запоздавший ответ не возвращает закрытую карточку; при ошибке доступны повторная попытка и предыдущие результаты очереди.
- Escape закрывает карточку и возвращает фокус на выбранный материал. Увеличены области нажатия, учтено предпочтение уменьшенной анимации.
- Граф перестраивается между горизонтальной и вертикальной раскладкой при изменении ширины окна без повторного запроса API.
- В форме загрузки есть счётчик символов, размеры файлов и состояние отправки. Уведомления можно закрыть. Завершение фоновой обработки не меняет раздел, если пользователь уже перешёл в другой.
- Очередь и сводка переводятся между русским и казахским без повторной загрузки данных.
