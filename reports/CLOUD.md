# Проверка облачного развёртывания

Дата: 25 октября 2026 года. Приложение: [safenet-kz.vercel.app](https://safenet-kz.vercel.app). Доступ защищён входом Vercel; прямой API Sandbox без серверного ключа возвращает 401. [Описание API](../API.md), [устройство развёртывания](../DEPLOYMENT.md).

## Подтверждённые результаты

- Полный набор Python: **275 успешных тестов**, без ошибок, пропусков и предупреждений; [cloud_tests.xml](cloud_tests.xml). Ruff и форматирование пройдены. В отдельном Node-прогоне два теста границ шлюза: запрещённые адреса/маршруты и превышение тела до подключения к облаку.
- `npm audit --omit=dev`: **0 известных уязвимостей** на момент проверки. Версия транзитивного `zod` закреплена совместимым исправленным выпуском через override; автоматическое принудительное понижение SDK не выполнялось.
- Статическая сборка русской документации и интерфейса прошла; синтаксис клиентского JavaScript проверен.
- Через опубликованный `/backend` обработаны **6 синтетических материалов**, включая скриншот с настоящим Tesseract. Сохранены **6 результатов и 3 решения аналитика**. Все задания завершены.
- Для связанного инвестиционного материала подтверждено ограниченное влияние графа **+15**. Граф: 6 материалов, 9 узлов, 4 ребра, 5 компонент; крупнейшая содержит 2 материала.
- Sandbox действительно остановлен через SDK. Последующий запрос к опубликованному API автоматически возобновил сервер. Сводка, исторический результат, три решения и идентификатор повторной команды совпали с состоянием до остановки.
- Через шлюз получен реконструированный PNG. Поток экспорта завершён маркером полноты; контрольное частное значение отсутствует. Русская страница README отвечает HTTP 200.

Машинный протокол: [cloud_smoke.json](cloud_smoke.json). Проверки используют `vercel curl` с действующей авторизацией владельца; секреты не входят в отчёт. Демонстрационные материалы независимы от закрытых выборок.

## Ограничения проверки

Этот прогон подтверждает работоспособность опубликованного API и восстановление после остановки, а не качество выявления, масштабирование или доступность 24/7. В браузере проверена локальная сборка интерфейса с тем же облачным API: загрузка очереди, открытие карточки, три оценки, объяснения и переход к цитате, историческая окрестность графа и фильтр казахского языка. Авторизованное открытие самого production-домена во встроенном браузере не удалось; HTTP-проверки опубликованных маршрутов выполнены через Vercel CLI. Полная браузерная приёмка всех сценариев ещё не завершена.

Проект впервые опубликован без ранее существовавшего production. Vercel автоматически назначил первое развёртывание production и выдал основной адрес; защита входом сохранена. Последующие изменения следует проверять в preview до продвижения.

Расширение с PostgreSQL, сбором и новыми моделями отложено по последнему указанию пользователя придерживаться ТЗ. Текущая публикация использует SQLite на постоянном Drive. Последующий редизайн и отдельная вкладка графа описаны в [UI_REDESIGN.md](UI_REDESIGN.md); этот первоначальный отчёт сохраняет результаты своей даты проверки.
