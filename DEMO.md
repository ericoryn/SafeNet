# SafeNet KZ — демо на пять минут

Запуск: `python tools/demo.py` из корня проекта при установленных Python и uv. Адрес: <http://127.0.0.1:8501>. Сайт и API работают в одном процессе; пустая база автоматически получает шесть синтетических материалов. База `data/demo.sqlite3` сохраняется между запусками. На Vercel используется отдельная облачная база.

| Время | Действие | Что сказать |
|---|---|---|
| 0:00–0:35 | Открыть очередь | Три направления проверки: платные розыгрыши, продвижение казино, инвестиционное привлечение. Система показывает признаки, окончательное решение принимает аналитик. |
| 0:35–1:10 | Переключить «Қазақша», затем «Русский» | Меню, ошибки и объяснения меняют язык; текст публикации сохраняется. Есть нормализация RU/KK, смешанного текста и транслита. |
| 1:10–2:00 | Открыть материал с оплатой и случайным выбором | Показать три независимых балла, вклады признаков и подсветку цитаты. Бесплатное участие и новостной контекст учитываются как контрпризнаки. |
| 2:00–2:40 | Открыть отдельную вкладку графа | Выбрать материал, нажать домен, показать соседей и хронологию. Граф ограничивает прибавку и не распространяет её каскадом. Связь не доказывает общность владельца. |
| 2:40–3:20 | Сохранить «Запросить проверку», обновить страницу | Решение связано с версией анализа и остаётся в истории. Повторный анализ создаёт новую версию. |
| 3:20–4:20 | Показать таблицу `reports/METRICS.md` | 240 синтетических тестовых материалов. Повторная регрессия: F1 розыгрышей 0,88; казино 0,50; инвестиций 0,68. Полнота казино 33,3%; остаются 32 пропуска из 48. Пороги 45/55 выбраны на validation до повторной проверки test. Это не новая независимая оценка. |
| 4:20–5:00 | Показать ROADMAP | Следующий шаг — улучшение качества на разработческой выборке, новый независимый тест и согласованный пилот с модераторами. Есть версия, измерения, история решений и план масштабирования. |

Для показа OCR загрузить синтетический PNG из `data/synthetic-v1/images` или отдельный демонстрационный скриншот. Дождаться завершения до начала выступления: загрузка в облако может запускать спящий сервер. Исходные пиксели заменяются безопасной реконструкцией распознанного текста.

Тайминг рассчитан на 300 секунд; живая репетиция докладчика не проводилась. Обновлены [PDF/PPTX и текст питча](presentation/README.md): 10 основных слайдов и 2 запасных. Сценарий живого демо — альтернативный вариант, не дополнительные пять минут.
